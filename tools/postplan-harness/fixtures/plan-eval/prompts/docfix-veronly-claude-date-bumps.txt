## Resolved design decisions

- Add a second, stricter tier for agent-steering files: `.claude/**`, `CLAUDE.md`, `AGENTS.md` PASS only when the file's whole diff is exactly one `-`/`+` pair on the frontmatter `last_verified:` line, strictly advancing. Any other change in those files (including numeric-only same-line swaps, `paths:` glob edits, body text) still HOLDs.
- `ibl5/docs/**` and `ibl5/classes/*/README.md` rules are unchanged.
- Status must still be exactly `M`. Adds/deletes/renames still HOLD. Every other path still HOLDs.
- Rationale: a date-only bump changes no agent behavior, and the nightly audit keeps flagging `.claude/rules/*` files, so each one otherwise needs a human merge.
- Do not touch Phase 6.5 arming conditions or post-plan; only the helper's predicate changes.

## Scope

1. `bin/docfix-check-veronly`: implement the stricter tier and update the Step 2.4 comment and `--help` text.
2. `bin/docfix-run`: update `$PROMPT` so it states the new rule accurately.
3. `bin/test-docfix-run`: date-only `.claude/rules/*.md` → PASS; `.claude` file with numeric same-line swap → HOLD; `.claude` with body change → HOLD; `CLAUDE.md` / `AGENTS.md` date-only → PASS and with other edit → HOLD; mixed diff (allowed doc + `.claude` date-only) → PASS in both row orders; mixed diff where the `.claude` file has more than a date bump → HOLD in both orders; non-advancing or equal date in a `.claude` file → HOLD. Rework cases 67/68a/68b/69 accordingly; keep every other existing case passing.
4. ADR-0104 `## Addendum — <topic> (<local date>)`, matching #2398's style; update ADR-0086 cross-ref only if it restates the allowlist. Bump `last_verified` on edited docs.
5. Only if `bin/docfix-run` computes `$TODAY` in UTC (check first): switch it to local date. PR #2559's reviewer saw `last_verified: 2026-09-30` written at 21:05 PDT on 2026-09-29, and `.claude/rules/doc-freshness.md` requires local date. If `$TODAY` is already local, the UTC date came from the agent or `bin/check-docs --fix-dates`; find which and fix at that source, or drop the item and say why.

Out of scope: merging or editing PR #2559; changing `bin/check-docs` future-date logic unless item 5 lands there; widening numeric edits to `.claude` files.
