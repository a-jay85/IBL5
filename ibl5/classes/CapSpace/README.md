# CapSpace

Calculates and displays salary cap space for each team. Follows the standard Repository/Service/View pattern. Entry point: `ibl5/modules/Contracts/index.php` (the Contracts page's Teams tab); `ibl5/modules/CapSpace/index.php` only redirects there.
